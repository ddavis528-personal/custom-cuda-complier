# sgemm-n512: sgemm.cu, N 512: A and B are 1024 KiB each; CTAs 0-15 of 2048, the first row band, so they share A's rows.
# One-warp CTAs, meant to run four resident on a core (CTA c on hardware
# context c mod 4), so they compete for L1 (AR's rev 229). Each CTA alone is
# ccv-sim kernel.bin -threads 32 -ctaid <cta> -context <cta mod 4>, the
# 'load' lines as -load=<addr>=<file> (files of little-endian words, in this
# directory), then that CTA's pokes. Results are checked bit for bit
# (export-kernels.py), and without the loaded inputs each CTA fails.
threads 32
resident 4
ctas 16
load 0x200000 A.bin 1048576
load 0x600000 B.bin 1048576
